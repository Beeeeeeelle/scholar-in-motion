# Support

## Using the template

Start with [README.md](README.md), [SETUP.md](SETUP.md), and [CUSTOMIZE.md](CUSTOMIZE.md). Questions about adapting the template belong in GitHub Discussions so answers can help other users.

## Bugs

Open a bug report when the template behaves incorrectly and you can provide reproduction steps. Include your browser, operating system, Ruby version, and the relevant build output.

## Feature proposals

Open a feature request for changes that could benefit the shared template. Personal content edits, custom deployment work, and general Jekyll support are outside the maintenance scope.

## Security

Follow [SECURITY.md](SECURITY.md); do not disclose vulnerabilities or credentials in a public issue.
